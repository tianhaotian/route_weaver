当天怎么走

乌里雅斯太镇 → G331 → 满都宝力格一带 → 宝格达山沿途 → 阿尔山市区

  1. 早餐后

    满电出发，先做路线判断

    出发前重新核实 G331 道路通行和低温天气，按至少 20% 的到达余量规划。

  2. 途中

    满都宝力格一带休息

    可作为休息、用餐候选，不能视作已确认补电点。

  3. 白天

    宝格达山沿途看秋色

    只在允许停车且视野安全的位置停靠，不在弯道、坡顶或窄路肩拍照。

  4. 天黑前

    到成悦核实侧面桩，补电与入住合并

    酒店页列有充电车位，住客提及侧面有桩，优先使用并争取 90%—100%；不可用就转备用公共站。次日退房后转住布谷名居。市区散步与火车站外观拍照视体力决定。
